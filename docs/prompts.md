# 主动保存与检索提示词

实现是结合行为原则重新编写的提示词，不直接复制两家产品的大段原文。

## 融合内容

| 来源 | 采用的行为 |
|---|---|
| ZCode | 稳定偏好、纠正、项目决策与引用四类；主动保存；创建前搜索查重；一条主题一个文件；默认项目作用域；无长期信息时返回空操作；成功轮后处理新增窗口。 |
| Claude Code | 记忆与当前指令分离；索引只是读取指针；保存偏好而非临时进度；追问历史决定时必须检索正文；易变事实必须重新验证；未提交前不声称已经记住。 |
| 本插件 | 统一使用 md_memory_* 工具；索引由存储层维护；更新带 revision/hash；短索引与正文使用独立预算；遗忘即时处理；后台提取没有工具权限。 |

主提示词在固定系统段注册，明确“应主动保存哪些信息”“哪些问题必须先检索”“用户要求记住必须当轮执行”。动态上下文只放条目目录和当次相关正文。

后台提示词单独定义：只判断新的真实对话窗口与候选清单，返回一个 JSON 对象，可合法返回空 operations。更新保留仍有效的事实并带当前修订/hash；不存在正文的候选只用于查重，更新交由主 Agent 读取后处理。

这些提示词提高主动写入和检索的概率；最终选择仍由模型完成。后台辅助调用补处理遗漏，不把主 Agent 任意一次写入当成整轮无需再分析的理由。

## 依据

- [ZCode 源码](https://github.com/zai-org/ZCode/tree/29628c9acdb81b703bbd4080c207a0e7ce5e276e)：核对过 memory 系统提示、extraction 与成功轮调度；完整路径与片段见工作区调研报告。
- [Claude Code 记忆文档](https://code.claude.com/docs/en/memory)：短 MEMORY.md 索引、主题文件、作用域与长期记忆边界。
- 工作区报告中 Claude Code 2.1.177 的本机提示词取证：历史细节的检索纪律及主动保存边界。其闭源后台完整控制流未被确认，本插件调度采用独立实现。
