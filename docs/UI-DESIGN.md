# 记忆管理页

以批准的 A 版三栏工作台为基础，使用 DSH 的颜色与字体，跟随宿主明暗主题。

## 记忆库

- 项目导航、紧凑记忆列表、编辑器分别滚动。项目过多、记忆过多或正文过长时，只滚动对应区域。
- 项目栏默认 200px，范围 160–320px；记忆栏默认 300px，范围 240–480px。宽度还受容器限制，编辑器至少 320px。
- 两个分界支持拖动；方向键每次调整 10px，Home/End 到最小/最大，双击恢复默认。仅中央灰色手柄在悬停、拖动或键盘聚焦时变蓝，整条分界保持原背景。
- 850px 以下项目留在左侧，列表与编辑器上下排列；600px 以下纵向排列，各区域保留滚动。窄布局隐藏拖动分界。
- 卡片单行标题、单行摘要、文件名及日期，常规高度约 80px。仅显示已有的停用状态，不提供类型筛选或置顶操作。
- 编辑标题、短摘要、Markdown 正文和匹配字段（标签、别名、关联路径）；既有文件名只读。参与召回开关沿用 active/disabled 状态。
- 编辑器抬头显示条目的上次修改日期与所属范围；新建草稿只显示范围。界面不再显示修订号。
- 页脚提供“移动”，把当前记忆交给下拉选中的用户记忆或其他项目。目标列表只包含真实项目；有未保存草稿时移动按钮禁用。确认后页面切到目标范围并重新打开该条目，原范围列表随之刷新。

## 配置

左侧分为召回、记忆写入、维护，右侧显示对应设置。切换分类保留未保存值；所有设置映射到既有配置字段。预算显示 KiB（1024 字节），超时显示秒，保存时换回字节与毫秒。目录及配置文件位置只读。

“召回”页在预算字段下方提供**跨项目访问**：每个项目一张卡片，卡片内是“用户记忆（跨项目共享）+ 其他项目”的勾选框（n 个项目就是 n−1 个其他项目加 1 个用户层）。抬头显示“已开放 k/n”，右侧提供“全部关闭”。项目超过 12 个时卡片默认折叠，并提供按名称、路径、id 过滤的输入框。卡片顺序与左栏项目一致，仅在宽度足够时双列排布。保存时把每个项目的勾选状态写成显式矩阵，`crossProject` 与其它配置共用一次保存与同一个 revision hash。

## 数据与操作约束

- 不改变存储、项目识别、索引排名、正文召回、后台提炼及工具协议；跨项目授权只改变“哪些记忆块可见”，且只开放读取。
- 编辑保留文件内已有 type、pinned 等未展示元数据；新建按范围填写 user/project 默认类型，不置顶。
- 写入、移动与删除使用原有 revision/hash 校验。冲突保留草稿并提示重新打开记忆，禁止覆盖最新正文。移动还要求目标范围没有同名记忆，命中时明确报错而不是覆盖。
- 保存期间表单与切换操作保持禁用。未保存草稿离开需确认；删除仍有明确确认。
- 配置依旧写入 SETTINGS.md 并即时应用；栏目分类与分栏宽度仅为界面状态，不增加存储方式。
